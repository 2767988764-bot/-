# 本地开发环境搭建（Windows・FastAPI + PostgreSQL）

> 用途：在本地把「数据库 + 后端工程 + 前端代理」三者打通，进入前后端联调。
> 顺序：先装库 → 再建后端工程 → 最后配前端代理。（因为后端工程需要连数据库）



***

## 第 1 步：本地安装 PostgreSQL 并建开发库

**1.1 安装 PostgreSQL**



1. 打开 PostgreSQL 官网（[postgresql.org](https://postgresql.org)）→ Download → Windows。

2. 下载安装包，安装时**记住你设置的超级用户密码**（`postgres` 用户的密码）。

3. 安装完成后，开始菜单会有 `pgAdmin 4` 和 `psql`。

**1.2 创建开发库和业务账号**（用 psql 或 pgAdmin 都行）

用命令行方式（打开 `psql`，输入刚才的超级用户密码）：



```
-- 建开发库（名称用 wms_dev，和后面后端配置一致）
CREATE DATABASE wms_dev;

-- 建一个业务账号（最小权限，别用 postgres 直接连业务）
CREATE USER wms_user WITH PASSWORD '你的业务密码';

-- 授权给业务账号
GRANT ALL PRIVILEGES ON DATABASE wms_dev TO wms_user;
```

**✅ 验收标准**：`psql -U wms_user -d wms_dev` 能连上这个空库，说明库和账号建好了。

> 备注：现在只建一个空库就够了，表结构等阶段 A2 用代码（SQLAlchemy）自动建，不用手工建表。



***

## 第 2 步：本地建 FastAPI 后端工程

**2.1 建目录 + 虚拟环境**（在你的项目根下，和前端平级）



```
cd D:\仓储管理系统
mkdir backend
cd backend
python -m venv venv          # 创建虚拟环境
venv\Scripts\activate        # 激活（命令行前出现 (venv) 即成功）
```

**2.2 安装依赖**



```
pip install fastapi uvicorn[standard] sqlalchemy psycopg2-binary pydantic \
            python-jose[cryptography] passlib[bcrypt] python-multipart
```

各依赖作用：



| 依赖                           | 作用                  |
| ---------------------------- | ------------------- |
| fastapi + uvicorn            | Web 框架 + 启动服务器      |
| sqlalchemy + psycopg2-binary | ORM + PostgreSQL 驱动 |
| python-jose                  | 签发 / 校验 JWT         |
| passlib\[bcrypt]             | 密码加盐哈希              |
| pydantic                     | 接口参数校验（FastAPI 自带）  |

**2.3 建最小工程结构**（阶段 A1 的骨架）



```
backend/
├── venv/                 # 虚拟环境（不进 git）
├── app/
│   ├── __init__.py
│   ├── main.py           # 入口：应用实例 + 健康检查
│   ├── core/             # 配置、安全（JWT/bcrypt 工具）
│   ├── models/           # 数据库表模型（SQLAlchemy）
│   ├── schemas/          # 请求/响应结构（Pydantic）
│   └── routes/           # 接口路由
├── requirements.txt      # 记录依赖
└── .gitignore            # 忽略 venv/、.env、__pycache__
```

**2.4 写一个最小&#x20;**`app/main.py`**&#x20;验证能跑**



```
from fastapi import FastAPI

app = FastAPI(title="WMS 仓储物流后端")

@app.get("/")
def health():
    return {"status": "ok", "service": "wms-backend"}
```

**2.5 启动后端**



```
uvicorn app.main:app --reload --port 9090
```

**✅ 验收标准**



1. 浏览器打开 `http://localhost:9090` → 显示 `{"status":"ok",...}`。

2. 打开 `http://localhost:9090/docs` → 出现 Swagger 接口文档页（FastAPI 自带，免费送）。

3. 端口用 **9090**，与 `后端对接说明.md` 里前端代理目标一致。



***

## 第 3 步：配前端代理，让前端连到本地后端

**3.1 打开&#x20;**`D:\仓储管理系统\vue.config.js`，找到 `devServer` 配置，取消 `proxy` 的注释，target 指到本地后端：



```
devServer: {
  // 开发环境代理：/api 转发到本地后端
  proxy: {
    '/api': {
      target: 'http://localhost:9090',   // ← 后端地址
      changeOrigin: true
    }
  }
}
```

**3.2 启动前端**（另开一个终端，在后端**保持运行**的情况下）



```
cd D:\仓储管理系统
npm run serve
```

**✅ 验收标准（联调闭环）**



1. 前端起来后，浏览器打开前端地址，能正常显示。

2. 前端发起的 `/api/...` 请求被转发到 `http://localhost:9090`。

3. 在 `utils/request.js` 里 `baseURL` 已是 `'/api'`，所以前端代码不用改 —— 只要代理通了，请求就会到后端。

4. 验证方式：临时把前端某处调 `request({url:'/'})` 或直接看浏览器 Network，`/api/` 请求返回后端的 `{"status":"ok"}` 即通。
